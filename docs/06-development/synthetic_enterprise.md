# Synthetic Enterprise Environment

## Overview
A realistic synthetic enterprise environment for evaluation and demo benchmarking.

## Example Services
- api-gateway
- user-service
- order-service
- payment-service
- inventory-service
- notification-service

## Scenarios Supported
- low-risk change
- large but isolated change
- breaking API change
- database migration
- Kafka/event schema change
- payment calculation change
- dependency change
- historical incident similarity
- successful deployment
- failed deployment
- rollback
- production degradation
