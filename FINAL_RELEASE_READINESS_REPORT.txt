DEMONSTRATING THE COMPLETE FLOW
================================
From GitHub change → code intelligence → investigation → LLM boundary → findings →
deterministic risk/policy/decision:

1. POST /api/v1/changes/propose with GitHub PR metadata and commit SHA
2. AnalyzeChange handler enqueues async worker job
3. Worker claims run, fetches diff via SourceControlPort.getDiff()
4. Worker fetches file content via SourceControlPort.getFileContent() at exact commit SHA
5. Worker runs deterministic risk assessment (DeterministicRiskEngine)
6. If RiskScore >= HIGH or TIER_0 service impacted OR explicit manual request:
   Worker enqueues InvestigateRisk command
7. InvestigateRiskHandler computes InvestigationCodeIntelligence
8. Code intelligence packaged as EvidenceRecord (source=OTHER, ref="CODE_INTELLIGENCE",
   origin=AGENT_DISCOVERED, title="InvestigationCodeIntelligence")
9. EvidenceRecord transported through agentPort.investigate(agentContext, risk, evidence)
10. LlmAgentPortAdapter.buildPrompt() recognizes code-intelligence evidence record,
    extracts complete 11-field InvestigationCodeIntelligence from JSON content
11. LLM prompt includes all fields: commit SHA, changed files, method signatures,
    imported types, direct callers, direct callees, impact graph edges,
    dependency paths, availability states
12. FakeLlmClient returns deterministic InvestigationFindings
13. Worker evaluates PolicyEngine against RiskAssessment + findings
14. GenerateDecisionHandler persists DecisionRecord (APPROVE/REVIEW_REQUIRED/BLOCK)
15. SourceControlPort.publishStatusCheck posts result to GitHub
