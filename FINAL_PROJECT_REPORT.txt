EXECUTIVE SUMMARY
==================
The Change Decision Intelligence (CDI) project has delivered its core value:
evidence-backed PR risk analysis that explains "this PR is risky because these
changed methods affect these dependencies, supported by this code/evidence,"
without merely producing "Risk = 40." 

Parts 1-12 of the implementation plan are complete. The original P0 vertical
slice (UC-01 through UC-04, UC-11/12) was already functional before this work.
Parts 9-12 added the P1 investigation agent pathway: code intelligence is
computed, packaged as an EvidenceRecord, transported through the existing
AgentPort contract, recognized and extracted by LlmAgentPortAdapter, and
included in the LLM prompt with all 11 structural fields. All deterministic
risk/policy/decision/GitHub behavior is preserved. The 717-test suite passes
with 0 new failures, and the FakeLlmClient ensures no external LLM dependency
in tests.

- GitHub PR ingestion, change metadata, diff analysis

  GitHub status
- Graceful degradation: LLM failure -> continue with deterministic risk only

ARCHITECTURE / DATA FLOW
========================
InvestigationCodeIntelligence  -->  EvidenceRecord (source=OTHER, ref="CODE_INTELLIGENCE", origin=AGENT_DISCOVERED)
      -->  ArrayList<>(fetchEvidence())  -->  agentPort.investigate(agentContext, risk, evidence)
      -->  LlmAgentPortAdapter.investigate()  -->  buildPrompt()  -->  LLM client (FakeLlmClient)
      -->  structured InvestigationFindings  -->  deterministic PolicyEngine  -->  DecisionRecord

The complete 11-field code intelligence reaches the prompt:
- commit SHA, changed files, method signatures, imported types
- direct callers, direct callees, impact graph edges
- dependency paths, availability states
- relevant source/diff information (via JSON content)
